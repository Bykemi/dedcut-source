DedCut — fait par ByKemi
Licences des composants tiers (version Tauri)
=============================================

DedCut utilise les composants suivants. Chacun garde sa propre licence.
Ces fichiers sont livrés avec le logiciel : LICENCES-TIERS.txt (ce fichier)
et LICENCES-RUST.txt (texte complet des licences des 245 briques Rust).


1. Tauri (MIT OR Apache-2.0)
----------------------------
La fenêtre et la partie Windows du logiciel sont construites avec Tauri
(https://tauri.app) et ses modules officiels : single-instance, global-shortcut,
dialog, opener. Avec leurs dépendances, cela fait 245 briques Rust, toutes sous
licences libres permissives (MIT, Apache-2.0, BSD, Zlib, Unicode-3.0, ISC,
Unlicense, CC0) sauf 5 sous MPL-2.0 (voir ci-dessous). Le texte complet de
chaque licence et la liste des briques sont dans LICENCES-RUST.txt.

MPL-2.0 (Mozilla Public License 2.0) : cssparser, cssparser-macros, selectors,
dtoa-short (projet Servo) et option-ext, utilisées par Tauri. Elles sont
utilisées sans modification. Leur code source est disponible sur
https://crates.io (par exemple https://crates.io/crates/cssparser) et
https://github.com/servo/rust-cssparser, https://github.com/servo/stylo.


2. Microsoft Edge WebView2 (non redistribué)
--------------------------------------------
L'affichage utilise le moteur WebView2 de Microsoft, déjà installé avec
Windows 10/11 (ou téléchargé depuis Microsoft par l'installateur s'il manque).
Il n'est pas inclus dans DedCut et reste sous la licence de Microsoft.
Les encodages H.264/AAC de l'export MP4 et de l'enregistrement d'écran sont
réalisés par WebView2 et Windows.
DedCut n'inclut pas FFmpeg.


3. React et react-dom (MIT), Tauri API (MIT OR Apache-2.0)
----------------------------------------------------------
L'interface est écrite avec React. Textes de licence à la fin de ce fichier.


4. mp4box.js 0.5.3 (BSD 3 clauses) — lecture des fichiers MP4
5. mp4-muxer 5.2.2 (MIT) — écriture des fichiers MP4
-------------------------------------------------------------
Intégrés pour l'export rapide. Textes de licence à la fin de ce fichier.


6. Installateur (NSIS, licence zlib/libpng)
-------------------------------------------
L'installateur Windows est créé par Tauri avec NSIS (Nullsoft Scriptable
Install System, https://nsis.sourceforge.io/License) et nsis-tauri-utils (MIT/Apache-2.0).

  Le moteur WebAssembly (dossier ort) est compilé à partir d'ONNX Runtime ; il peut contenir des
